# Retail Sales Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on analyzing retail sales data to identify sales trends, customer purchasing patterns, product performance, and regional sales performance. Exploratory Data Analysis (EDA) was performed using Python libraries to generate meaningful business insights.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify yearly, monthly, and quarterly sales trends.
- Compare sales across product categories and sub-categories.
- Analyze region-wise and segment-wise sales.
- Identify top-performing products and customers.
- Analyze shipping modes and delivery time.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Project Workflow
1. Data Loading
2. Data Inspection
3. Data Cleaning and Preprocessing
4. Feature Engineering
5. Exploratory Data Analysis (EDA)
6. Data Visualization
7. Business Insights and Recommendations
8. Exporting Cleaned Dataset

## 📊 Analysis Performed
- Year-wise Sales Analysis
- Month-wise Sales Analysis
- Category-wise Sales Analysis
- Sub-Category-wise Sales Analysis
- Region-wise Sales Analysis
- Segment-wise Sales Analysis
- Top 10 Products by Sales
- Top 10 Customers by Sales
- State-wise and City-wise Sales Analysis
- Shipping Mode Analysis
- Shipping Days Analysis
- Correlation Heatmap

## 💡 Key Outcomes
The project provides an overview of retail sales performance and helps identify important sales patterns, high-performing products, customer segments, and regional trends.
